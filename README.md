- تثبيت البرنامج أو تحديثه يتم من داخل البرنامج نفسه. للاستفسار أو لطلب نسخة: ultracrm@ultracrm.ae

استخدام البرنامج يخضع لترخيص من شيفرة.

## English

This repository holds **ready release packages only** for Ultra CRM. It contains no source code.

- Every version is on the [Releases](../../releases) page as a zip with a signed `manifest.json`.
- Client installs verify the signature before installing, reject any package not signed by Shiffera, and take a backup before updating.
- The release workflow fills this repository automatically. Never upload files here by hand.
- Installing or updating is done from inside the application. Questions or a copy: ultracrm@ultracrm.ae
